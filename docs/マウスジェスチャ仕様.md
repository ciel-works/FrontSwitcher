# マウスジェスチャ対応 仕様（v1.2.0）

2026-09-24 確定（同日改訂：距離のカスタマイズ・キー組み合わせを追加）

**概要**
・右ボタンを押したままマウスを動かし、方向の並び（例：↓→）で動作を実行する
・ホットキーとは別の入口。ホットキーの動作は今まで通り
・既定はOFF。設定画面でONにして使う
・描いている間の軌跡表示はしない（目立たせない）

**判定**
・右ボタンを押した地点から「開始距離」以上動いたらジェスチャ開始
・上下左右の4方向。同じ方向が続く間は1ストロークとして数える
・別の方向へ「方向転換距離」以上動いたら、次のストロークとして数える
・距離はどちらも設定画面で数値入力できる（5〜300px、既定は開始20px／方向転換30px）
・画面の拡大率（125%・150%など）に関係なく、画面上の実際のピクセルで数える
・最大4ストロークまで。それを超えたら不成立
・右ボタンを離した時点で、登録済みの並びと完全一致したら実行する
・一致しなければ何もしない（右クリックも出さない）
・開始距離未満で離したら、普通の右クリックとして流し直す（右クリックメニューは今まで通り出る）
・右ボタンを押したまま左クリックやホイールを使った場合はジェスチャを中止し、通常の操作として扱う

**キーボードとの組み合わせ（任意）**
・ジェスチャごとに、Ctrl／Shift／Alt／Win を組み合わせて指定できる（指定なしでも可）
・例：Ctrl＋↓＝閉じる、↓（キーなし）＝隠す のように、同じ並びでもキーの違いで別の動作にできる
・キーは右ボタンを押した瞬間の状態で判定する。押している途中でキーを変えても判定は変わらない
・キーは完全一致で判定する（Ctrl＋↓ の登録は Ctrl＋Shift＋↓ では動かない）
・右ボタンを押した瞬間のキーの状態に合う登録が1件も無ければ、ジェスチャは始めず右ボタンをそのまま流す
・これにより、全部のジェスチャをキー付きで登録すれば、普段の右ドラッグ（エクスプローラーのコピー・移動など）は今まで通り使える
・Alt・Win はジェスチャ後にキーを離すとメニューバーやスタートメニューが開いてしまうため、ジェスチャが成立したときはこれを抑える
・対象は修飾キー4種のみ。無変換などの一般キーは、キー本来の入力を止める仕組みが別に必要になり誤作動も増えるため対象外

**対象ウインドウ**
・一般的な窓操作（最小化・最大化・閉じる）は、ジェスチャを始めた地点のカーソル下にあるウインドウ（トップレベル）が対象
・FrontSwitcher 固有の動作（隠す・戻す・切替・前面へ）は、ホットキーと同じ判定をする

**割り当てられる動作**
・隠す：前面ウインドウと登録アプリをまとめて最小化し、タブも閉じる（トグルの「隠す」側だけを必ず実行）
・戻す：隠したウインドウを全部戻す（トレイの「隠したウインドウを戻す」と同じ）
・切替：ホットキーと同じトグル
・対象アプリを前面へ：基本タブの対象アプリを前に出す（起動していなければ起動する）
・最小化：カーソル下のウインドウを最小化
・最大化／元に戻す：カーソル下のウインドウを最大化。最大化済みなら元のサイズに戻す
・閉じる：カーソル下のウインドウを閉じる（WM_CLOSE。保存確認などはアプリ側の動きに任せる）

**既定の割り当て**
・↓＝隠す
・↑＝戻す
・ほかは未割り当て

**除外アプリ**
・登録したプロセスが前面、またはカーソル下にあるときはジェスチャを無効にし、右ボタンをそのまま流す
・右ドラッグを自分で使うアプリ（ゲーム、リモートデスクトップ、CADなど）向け
・上限20件。入力方法は「一緒に最小化」タブと同じ（手入力＋前面取得）

**設定画面**
・新しいタブ「マウスジェスチャ」を追加
・マウスジェスチャを使う（ON/OFF）
・ジェスチャ一覧（キー／方向の並び／動作）。追加・削除。上限10件
・方向は ↑↓←→ ボタンで入力し、「クリア」ボタンで消す
・キーは Ctrl／Shift／Alt／Win のチェックボックスで指定（すべて外せばキーなし）
・同じ「キー＋並び」の二重登録はできないようにする
・開始距離・方向転換距離（数値入力、5〜300px）
・除外アプリ一覧

**トレイメニュー**
・「マウスジェスチャ一時停止」を追加（チェック式）。トラブル時にすぐ止められるようにする
・一時停止の状態は保存しない（再起動したら設定どおりに戻る）

**設定ファイル（settings.json に追加）**
・MouseGestureEnabled（bool、既定 false）
・MouseGestures（キー＋並び＋動作のリスト。並びは "D", "UR" のような文字列＝U/D/L/R、キーはホットキーと同じ MOD_* の組み合わせ）
・GestureStartDistance（int、既定 20）
・GestureStrokeDistance（int、既定 30）
・GestureExcludeProcesses（プロセス名のリスト）

**実装方針**
・低レベルマウスフック（WH_MOUSE_LL）を新しいクラス MouseGestureService にまとめる
・アプリは管理者で動いているため、管理者権限のアプリ（MCBookViewer など）の上でも拾える
・フックの中では座標の記録と判定だけ行い、動作の実行はUIスレッドに回す（フックが遅いと Windows に外されるため）
・修飾キーの状態は GetAsyncKeyState で右ボタン押下時に取得する
・Alt／Win の抑止は、ジェスチャ成立時にダミーのキー入力（VK 0xE8 等の未使用キー）を1回送る方法で行う
・右クリックの流し直しは SendInput。自分が送った入力はフラグで見分けて素通しする
・WindowSwitcher は、トグルの中の「隠す」「戻す」を単独で呼べる公開メソッドに分ける
・動作ごとの処理は GestureAction の列挙型＋実行メソッドで振り分ける

**気をつける点**
・Chrome のジェスチャ拡張など、右ドラッグを使う仕組みとぶつかる → 除外アプリで回避
・フックが外された場合に備え、一定間隔でフックの生存を確認して張り直すかは実装時に検討する
・キーなしのジェスチャを登録していると、右ドラッグ（ファイルのコピー・移動等）が使えなくなる → キー付きで登録するか、除外アプリ（explorer）で回避できると案内する
